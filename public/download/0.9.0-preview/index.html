安装与使用

  1. 下载后，在安卓安装器或卓易通中打开 APK，按提示覆盖安装；关闭旧应用再打开。
  2. 到“设置 → 版本与更新”核对当前安装版为 0.9.0-preview。网页内容更新，不代表安装包已更新。
  3. 点麦克风打开系统语音界面，识别后检查文字并手动发送。没有系统语音服务时，可使用输入法麦克风。
  4. 到“设置 → 提醒设置”允许系统通知并试推；保存日常/用药时间后检查同步反馈。若未出现，请检查系统通知类别、勿扰及卓易通后台设置。
  5. 生成分享图后点保存；看到真实保存确认，再到当前安卓环境图库或文件管理的 Pictures/Shichen 查看。也可使用系统分享面板。
  6. 在“数据接入与权限”查看实际读数；没有数据仍由聊天补充，不自动编造。

安装版首次启动需要联网。0.9已完成构建、策略检查与签名校验；通知、后台唤醒、保存与分享在卓易通中的实际表现仍需真机复核。系统语音服务可能联网；文字不会自动发送。已保存/分享的图片不会随清除应用资料自动删除，请另到图库或文件管理中删除。
