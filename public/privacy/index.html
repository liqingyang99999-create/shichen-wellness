一、当前处理的信息

聊天与行动卡

你发送的文字、当前或模拟时间、时区、明确补充的活动条件、看屏/久坐/活动时长、用餐阶段、情绪或清醒状态，以及可用的城市天气，会用于理解情境、检索固定卡库和解释选卡理由。打开应用时，也会按时间和已保存条件请求一张卡片。

手机入口每次提交当前文本及有效的结构化情境，不把整个聊天记录作为历史消息重复发给模型。最近卡片编号用于避免重复推荐。聊天原文不自动脱敏，请不要输入密码、身份证号、精确住址或他人的私密信息。

定位与城市天气 可选

首次获取位置需要你通过系统授权。我们读取经纬度、定位精度和采集时间，在本机判断是否匹配你保存的家或公司。联网查天气、识别城市前，将经纬度四舍五入到小数点后两位；降低精度后仍属于位置相关信息，并不等于匿名数据。

在已有定位授权且未保存手动城市的情况下，打开应用会尝试刷新当前位置和天气；不会因此再次弹出首次授权。你也可以拒绝定位，手选国内城市。保存过的城市可在启动时用于刷新天气。城市名称识别另有默认关闭的 BigDataCloud 开关，已有系统定位授权不等于同意使用该服务；未开启时，定位天气显示“当前位置”。

家/公司的详细地址、明确选择保存的坐标及地点条件存于本机，不由该设置功能上传给模型。使用地点预设后，选卡所需的活动条件仍会随情境发往云端。

屏幕使用与前台步数 安卓安装版 · 可选

取得系统使用情况访问授权后，安装版查询当前安卓环境的使用事件，仅提取亮屏、灭屏及重启时间，计算今日已记录时长或部分片段；为判断零点状态，查询可能回看最多七天，但不跨越当前启动边界。程序不建立或上传各个应用的使用明细。

取得活动权限且设备提供传感器时，安装版累计本次打开期间实际观测到的前台步数。上述读数只在本机设置页展示，不上传到模型，也不当作连续看屏时长或华为健康全天步数。卓易通是否提供宿主数据以实际设备为准。

语音转文字 可选

点击底部麦克风后，安卓安装版调用设备提供的系统语音识别界面；支持的浏览器使用其语音识别服务。相应服务可能通过网络处理声音，具体由你选择的系统或浏览器服务决定。安卓安装版不申请直接录音权限；网页使用语音时可能出现浏览器的麦克风权限提示。

本应用不保存录音，也不把声音上传到本项目服务器；收到的识别文字先进入可编辑输入框，只有你点击发送后，才按聊天流程交给云端模型。可以取消识别或直接打字；识别服务不可用时可使用输入法自带的语音功能。

偏好、诊断与主动联系

本机保存大字模式、活动条件、地点预设、城市识别选择、天气缓存及提示已读状态。时间来自设备时钟，界面按北京时间组织时辰。

只有你点击“复制诊断摘要”时，应用才将版本、系统 API、权限与传感器状态写入系统剪贴板；摘要不含位置、地址、健康读数或聊天内容，不会自动上传。你主动发邮件反馈时，我们会处理你的邮箱、反馈内容和你自愿附上的资料，以答复和排查问题。

当前没有用户注册、广告投放、通讯录/相机采集、应用自建录音上传、穿戴设备同步或后台健康监测功能。网络访问会产生提供服务所需的技术信息，见下一节。

二、第三方服务与网络传输

当前使用以下服务。对相关数据的处理不能仅通过“清除手机记录”全部撤回；服务商有自己的处理规则。本政策说明本应用的实际传输，不将第三方政策当作我们的免责条款。

手机或浏览器语音服务

语音转文字由当前设备或浏览器提供的识别服务完成。该服务可能在线处理声音，也可能支持离线识别，本应用无法保证全程离线；其运营者、数据保存及处理地区以设备选择的服务和该服务告知为准。开始识别前会说明这点，是否使用由你决定。

Cloudflare：网页托管和 API 处理

网页内容与请求由 Cloudflare Pages / Workers 提供。聊天与情境请求、城市查询和降精度天气坐标经过该基础设施。Cloudflare 处理网络请求以及 IP、路由、系统配置等技术信息；其公开政策说明存在全球处理和国际传输。我们不能保证数据全部只在中国境内处理或不存在平台日志。Cloudflare 隐私政策。

DeepSeek：理解情境与生成解释

服务器将当前聊天原文、相关情境发送给 DeepSeek API。后续查询和解释使用结构化情境、卡片主题与来源片段。模型密钥保存在服务器，不放入网页。我们没有核实当前服务账户是否启用特殊数据保留或训练排除安排，因此不作“零保留”或“不用于训练”的承诺。DeepSeek 隐私政策。

Open-Meteo / GeoNames：天气与城市搜索

服务器向 Open-Meteo 请求天气或城市搜索，发送两位小数坐标或你输入的城市名称。城市搜索使用 GeoNames 数据；本应用不另行向 GeoNames 网站发送搜索请求。请只在城市搜索框填写城市，不填写门牌地址。服务商可能保留其服务所需的技术记录。Open-Meteo 条款与隐私说明。

BigDataCloud：根据当前定位识别城市

只有你在定位设置中明确开启默认关闭的“允许 BigDataCloud 识别城市名”后，定位时或已获授权的启动刷新才会调用这项服务。浏览器直接向 BigDataCloud 发送两位小数坐标和语言参数，该服务同时能接收到设备的网络 IP。其官方说明指出，免费客户端接口会匿名聚合坐标与 IP 的配对信号，用于改进 IP 定位数据。可随时在定位设置中关闭；关闭后停止新的识别请求并取消尚未完成的请求，不能撤回已发送的数据或自动删除已有天气显示。关闭此选项仍能定位查天气或手选城市；手选城市不调用这项识别服务。BigDataCloud 隐私政策 · 免费接口数据用途说明。

上述网络服务可能涉及境外处理。提供必要的告知、适用的单独同意及其他依法应履行的程序，是接入方应落实的事项；本页面的公布不代表相关认证或程序已经完成，也不以默认勾选或单纯浏览本页面代替你的同意。

点击卡片的外部来源链接后，你将访问对应网站，其网络请求由该网站处理。景物配图和页面样式随本项目托管，不从外部图库或字体网站加载。

三、保存期限与删除方式

  • 本次聊天和结果：保存在当前页面内存，手机界面最多显示二十条聊天记录。设置中的“清除本次对话”会清除显示记录、当前结果及选卡情境；刷新或结束页面会话也会失去这些内存状态。聊天提取的情境最多复用三十分钟，这不是云端供应商的保留期限。
  • 本机偏好及地点：保存在浏览器或 WebView 的本地存储，没有统一自动过期时间。可在主屏左上角“活动条件”中清除活动条件，在设置的定位区域逐个删除家/公司预设；完整删除城市、缓存、已读标志等，请清除此网站数据，或在系统设置中清除安装版的应用数据。卸载前请确认是否需要保留自己的预设。
  • 天气：缓存采集时间在六小时内的天气可被复用。六小时是有效性检查，不是保证到时自动销毁的期限；完整清除可使用上述网站/应用数据删除方式。
  • 原生统计：计步与亮屏汇总仅保存在运行内存，亮屏查询短时缓存约五秒；不建立本地或服务器健康历史库。系统自己的使用记录不由本应用删除。
  • 服务器与第三方：本项目没有用于长期保存聊天或健康记录的业务数据库，API 响应标记为不缓存；这不等于 Cloudflare、模型或天气服务没有网络与服务日志。第三方保存、删除及依法留存范围受其规则和实际处理情况约束，不能由本机清除按钮直接删除。
  • 主动反馈：通过邮箱联系产生的资料仅用于处理请求及必要的后续核查。你可要求删除；如存在依法需保留的内容，我们会说明原因和处理范围。

四、华为运动健康接入计划

当前为申请和准备阶段，尚未接入。目前不读取华为账号中的运动健康记录，也未保存华为健康授权令牌。

计划申请五类只读数据：步数；距离、爬高与海拔；心率；压力；睡眠。计划用途是结合个人活动与睡眠趋势，帮助安排日常小行动和回顾生活节律，不用于疾病诊断、治疗或医疗风险预测。

计划申请的历史读取范围最多为过去一年，实际可读范围由华为审批、接口能力及你的授权共同决定。“一年历史”表示可能查询的时间范围，不表示我们将数据保存一年，也不表示必须读取全部历史。

在任何实际读取之前，我们会按最终实现更新本政策，明确必要的数据项目、时间范围、处理位置、保留和删除方式、是否向模型或其他服务传输，并取得相应的单独授权。你可不连接或撤回授权，继续通过聊天和手动条件使用其他功能。本次政策不作为未来读取健康数据的预先授权。

五、你的选择与权利

  1. 拒绝或撤销权限：在手机系统或浏览器的应用/网站权限中关闭定位、使用情况访问或活动权限；BigDataCloud 城市识别可在应用设置的定位区域单独关闭。关闭后相关自动数据可能不可用，聊天与卡片浏览仍可使用。
  2. 修改与删除：在设置中编辑或删除地点预设、清除本次对话，在主屏左上角“活动条件”中清除已补充条件；需要彻底重置时清除网站或应用数据。清除本机内容不会自动删除已经发送给服务商的处理记录。
  3. 查询、复制、更正或提出异议：请联系 liqingyang66666@126.com，说明请求类型、使用日期和可协助定位问题的最少信息，不必先提供身份证件或完整健康记录。我们会核实请求，说明能够处理的范围；涉及服务商保存的内容，会在可行范围内协助提出请求并说明限制，不以此免除自身责任。
  4. 停止使用：本应用没有用户账号，无需注销。你可以停止联网使用、撤销系统权限并删除本机数据；这些操作不影响撤回前依法进行的处理。

我们不把同意非必要权限作为卡片浏览的条件。选择不发送聊天文字时，仍可按时间和手动条件查看卡片；联网功能本身仍会产生请求。

六、保护、未成年人、联系与更新

我们采用 HTTPS 传输，服务器保存模型密钥，并对手机接口输入和原生桥来源作限制。当前没有广告追踪或出售个人信息的功能。本机偏好使用系统浏览器/WebView 的普通本地存储，并未另行加密；请留意共用设备、截屏和剪贴板分享。

本应用面向成年人的日常生活场景，不主动面向未成年人采集健康数据。若发现误收集未成年人或他人信息，请联系运营者处理。我们不会因你拒绝提供不必要的个人信息而取消其他不依赖该信息的功能。

出现个人信息安全事件时，我们会采取必要补救措施，并依法履行通知等义务。你可以通过上述邮箱提出问题、投诉或个人信息请求。运营者：李青洋；邮箱：liqingyang66666@126.com。
