本网页默认使用DeepSeek理解表达、追问和匹配卡片；必要的本次描述与情境摘要经服务端发送。完整资料和记录仍保存在本机。服务不可用时自动使用基础匹配。

一、保存在设备上的内容

个人资料与体质倾向

你填写的称呼、年龄、身高、体重、疾病选项、限水或行动限制、过敏说明，以及问卷版本、体质结果和评估时间，用于调整候选行动。称呼可使用昵称。

记录与提醒

你录入的血压、脉搏、测量时间，用药名称、时间和备注，以及主诉标签、行动完成、自评、计划机会和通知记录，保存在本机。它们用于趋势展示、回顾和你设定的提醒。

当前聊天与卡片历史

输入与语音转写在本机参与基础情境识别；必要片段另按下方说明发送；尚未处理完的澄清或安全提示可能保留必要的原文，以免刷新后遗失上下文。卡片编号、展示时间、类别与动作类型另作去重记录。城市、天气结果及提醒设置也保存在本机。

个人模式与竞赛模式使用不同的本机记录；演示值会标记为模拟。当前没有账户云同步或健康数据云备份。本机网站存储没有额外应用层加密，请使用自己的设备，并妥善管理锁屏和系统账户。

二、哪些功能需要联网

AI理解与选卡 · DeepSeek

本网页默认使用AI；首次填写资料时提供简短说明和本政策入口。经Cloudflare服务端将本次描述、最多六条近期对话及必要的体质倾向、疾病限制、可用体征或当前血压摘要、天气温度、时辰和去重信息发送到DeepSeek API，用于理解口语、提出追问、从合格卡库中选择并解释。请求不会附带资料中的姓名、联系方式、准确位置或完整健康历史；请不要在自由输入中加入不必要的身份信息。

服务端不建立健康记录数据库，也不主动记录请求正文。模型服务方会处理提交内容，其保留和使用规则见DeepSeek隐私政策；本应用不承诺第三方零留存。连接仍会产生必要的网络与限流信息。关闭网页后不再由该页面发起后续模型请求，已发出的内容不能通过本机清理撤回。AI不可用时明确显示基础匹配；急症拦截不等待模型。

网页、安装包与版本检查 · Cloudflare

打开页面、加载图片、检查版本或下载 APK 时，请求由 Cloudflare 托管网络处理。常规连接信息可能包括 IP 地址、请求时间和浏览器信息；本版不把个人资料或健康记录附在这些请求中。详见Cloudflare 隐私政策。

天气与城市搜索 · Open-Meteo

点击定位并允许后，页面将经纬度四舍五入至小数点后两位，通过 HTTPS 向 api.open-meteo.com/v1/forecast 查询天气。搜索城市时，输入的城市查询词发送至 geocoding-api.open-meteo.com/v1/search；选定城市后用该城市坐标查询天气。请求不携带姓名、血压或主诉，当前不保存家庭或公司地址。

服务方会接收到 IP 和查询参数，其政策说明 API 日志可能含坐标并保留至90天；城市索引来自 GeoNames。参阅Open-Meteo 条款与隐私说明及城市搜索说明。不使用天气功能时，不发起这些查询。

可选城市名识别 · BigDataCloud

只有你勾选允许、并通过当前位置查天气时，页面才将同样约略的坐标发送至 api.bigdatacloud.net/data/reverse-geocode-client。该服务也会接收到请求 IP，用于识别城市名。关闭这一选项不妨碍天气查询，可改为手选城市。

这是独立第三方服务，其政策说明数据可能在澳大利亚或美国等地处理。参阅BigDataCloud 隐私政策。

语音转写 · 手机或浏览器提供的服务

语音只在你主动操作并确认说明后启动。安卓安装版打开系统语音界面；网页版使用浏览器可用的语音服务。服务商可能联网处理声音，具体以你使用的系统或浏览器说明为准，不能保证离线。本站不接收或保存录音，只接收识别文字；文字先进入输入框，由你编辑并手动发送。取消语音不会自动发送内容。

上述网络服务可能在境外处理相应请求。你可以不使用定位、城市识别或语音，继续以文字和手选城市使用应用。访问来源链接、邮件或系统分享时，将进入你主动选择的服务。

三、权限与设备数据

  • 定位只在查询天气时申请，不做后台位置追踪。拒绝后可搜索或选择城市。
  • 安卓活动权限与使用情况访问由你在系统中确认。页面仅展示当前安卓环境返回的前台步数和屏幕汇总；不把缺失数据补成0，不把汇总当作连续看屏或鸿蒙全机统计。
  • 华为健康、心率、睡眠和可穿戴数据仍未接通。接口占位或其他权限已开启，不代表获得了健康数据。
  • 系统通知由你主动允许，可能显示在锁屏上。0.9 安装版在本机保存提醒类别、标识、时间、夜间选项和最近30条通知回执，并通过安卓非精确闹钟安排提醒；原生日程与通知不包含药名、病史或血压。普通提醒在23:00—05:00静默；夜间用药通知默认关闭，可单独选择静音显示，不改变原医嘱时间，也不会判断真实睡眠。网页需保持运行；系统省电、强制停止和卓易通环境可能延迟或阻止通知。

打卡分享图在本机生成，包含日期与行动标题，不含姓名、病史或血压。点击保存后，0.9安装版写入当前安卓环境的 Pictures/Shichen，并保存最近100个本应用图片 URI 以支持系统分享。Android 10及以上不申请全部相册或文件访问；Android 9保存时单独申请写入权限。卓易通的媒体库不一定映射到鸿蒙宿主图库，可以通过系统分享导出。网页下载仅表示请求浏览器保存，不等同于进入图库。分享目的地由你选择。

四、查看、更正与删除

你可在设置中更新个人资料，在用药页新增、暂停或删除提醒，并在浏览器或系统设置撤回位置、语音及通知等权限。停止某项权限不会自动删除已保存在本机的记录。

本版暂未提供一键导出或逐条删除所有记录的功能。要删除全部本机资料，网页版请在浏览器设置中清除本站的网站数据／存储（仅清缓存可能不够）；安卓安装版可在系统或卓易通的应用管理中清除本应用数据，或卸载。这样会同时清除个人与竞赛记录、去重历史和设置，且没有云备份可恢复。已保存到共享媒体库或下载目录的图片不会随应用资料自动删除，请另在图库或文件管理中删除。不同浏览器、APK 和预览域名的存储彼此独立，需分别清理。

资料通常保留至你主动清理；去重记录在后续运行时按最近八天合并清理。运营者无法远程读取或替你删除仅存于本机的资料，可协助说明操作方法。若你主动发送邮件反馈，邮件地址及所附内容仅用于处理该反馈；不必发送完整病历、密码或密钥。

五、适用范围与联系

本项目面向成年人日常使用与竞赛体验，没有未成年人专用功能，也不要求身份证、通讯录或相册访问。本版未接入广告追踪，不出售个人健康记录。后续若增加其他模型服务商、云同步或真实健康平台，将在启用前更新说明并按具体用途请求授权。
