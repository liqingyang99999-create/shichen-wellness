## 第4页｜AI负责理解与选择，规则约束可执行范围

**一句自然表达 → 语义理解 → 条件筛选 → AI选卡 → 再次复核 → 展示理由**

- DeepSeek理解感受、情绪、事件、活动意愿及前后文变化。
- 本地规则优先处理危险表现；设备异常先核对本人感受。
- 已知限制、夜间规则与冷却机制筛掉不合适的卡片。
- AI只从合格候选中选择，并生成“为什么推这张”。
- 卡片动作沿用内容库原文；结果再次检查后才显示。

画面：六步横向流程。急症规则单独置于入口上方，指向求助卡。

讲解备注：语音转写由系统或浏览器提供；实时选卡的语义理解与候选选择已经接入DeepSeek。AI不可用时页面如实显示基础匹配。

## 第7页｜30秒之后，留下可回看的行动记录

**开始行动 → 30秒计时 → 本人确认/反馈 → 护心日历**

- 轻微不适的行动后，可反馈“已缓解、差不多、加重或新不适”。
- 改善后保留休息提示；由本人决定何时回到日常陪伴。
- 确认完成记1次；护心值记录行动，不是健康评分。
- 日历呈现完成情况、计划完成率和主动填写的前后感受。

画面：完整计时、反馈按钮、日历三步串联。本次实跑使用“把下颌轻轻放松”完整计时30秒，反馈已缓解后，护心值15→16、当日完成1→2，最近完成中出现该卡和15:30时间。

讲解备注：计划完成率以到时计划为分母，聊天出卡与主动换卡不增加分母；未填写的感受不会自动记为改善。
