# 手机卡片配图

2026-11-04 使用内置图像生成工具为本项目生成四张独立实景风格配图。它们是 AI 生成的装饰性景物，不是动作示意图、穴位定位图或真实地点照片。来源按钮始终对应卡片知识来源，不对应背景景物。

| 文件 | 场景 | 推荐用途 |
|---|---|---|
| `public/scenes/bamboo.webp` | 竹林、远山、晨间光影 | 舒展、手部小动作、远眺 |
| `public/scenes/water.webp` | 湖水、涟漪、绿叶 | 自然呼吸、安静休息、饮水 |
| `public/scenes/night.webp` | 月色、松枝、远山 | 夜间与睡前收束 |
| `public/scenes/leaves.webp` | 银杏、秋日山野 | 秋冬节气、外出与生活整理 |

生成提示词共同约束：竖向 2:3、自然写实摄影风格，景物集中在底部三分之一与右缘；上方及左侧保持近白雾气与留白；所有边缘自然渐隐；不包含人物、文字、标志、UI 或动作示范。四个场景分别指定竹林、湖水、月夜和银杏。原始图片为 1024×1536，使用 FFmpeg 转为 WebP（质量 85）供应用加载；没有把整张设计概念图当作界面。

标题、步骤、出处、按钮均为可访问的真实 HTML 内容。卡片切换使用渐显，尊重系统减少动态效果设置。大字体和长步骤允许页面滚动，不能为了背景图遮挡或截断动作。
