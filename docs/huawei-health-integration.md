# 华为运动健康接入准备

核对日期：2026-11-04。当前接入准备按已实名的个人开发者进行；运动健康服务尚未申请，Android APP ID 列表为空。本文件记录接入准备，不代表服务已经开通。

## 当前版本

当前 Android APK 通过卓易通在用户的 HarmonyOS 手机上运行，网页与聊天出卡已可使用。原生位置、系统使用情况访问和计步传感器是三种独立能力；它们不会自动授权读取华为运动健康的步数、睡眠或运动记录。

**当前未集成华为运动健康 SDK 或云侧授权读取。** 设置中应显示“本版本尚未接入”，不能将此状态解释为用户漏开了活动权限。没有数据时保留未知，并继续允许用户通过聊天补充状态。已安装 APK 也不等于原生 HarmonyOS 应用。

## 两条候选路线

| 路线 | 需要完成的事项 | 在当前手机上的限制与待确认事项 |
| --- | --- | --- |
| Android SDK | 登记 Android 应用与包名、配置签名指纹及 AGC 文件；申请数据权限；集成 Account Kit / Health Kit；由用户登录华为账号并授权 | 官方 Android 示例使用 HMS Core 环境。卓易通内的 HMS Core、账号授权、与宿主华为运动健康的数据连通性必须实测；当前不能承诺可直接读到宿主数据 |
| 云侧 API | 登记符合要求的应用/服务，申请相应数据权限；实现账号授权、服务端凭据管理、数据读取与撤销授权；核实华为健康的数据开放授权 | 官方有 Web 和云侧接口，可作为减少跨容器 SDK 依赖的候选方案。仍受开发者主体、产品类型、服务审批、用户授权、数据同步和地区规则约束，不是绕过审核的方法 |

Android 官方示例明确要求应用、包名、签名指纹和 AGC 配置，并通过华为账号与健康数据授权读取记录。[Android SleepTracker Codelab](https://developer.huawei.com/consumer/en/codelab/SleepTracker/)

官方云侧 FAQ 说明，应用审批权限、授权时使用的 appId 和用户勾选的 scope 必须相符；不同数据站点还可能需要按服务响应处理路由。不得仅取得一个 token 就假定所有数据均可读。[云侧 FAQ](https://developer.huawei.com/consumer/fr/doc/hmscore-guides/faq-0000001476980529)

## 开发者控制台的最小下一步

先登记与当前安装包匹配的 Android 应用，再核对实际服务申请页；不得把“APP ID 创建成功”显示为“运动健康已接入”。

1. 用户登录已实名认证的华为开发者账号，查看主体是“个人”还是“企业”，并确认使用主账号。不要发送账号密码、身份证件或验证码。
2. 在管理中心进入 AppGallery Connect，查看“我的项目/开发与服务”中是否已有“时辰心管家”。若没有，先记录未创建，不为核对资格而重复建项目。
3. 查看 Health Service Kit / 运动健康服务的申请入口。界面可能位于服务卡片，或项目的开放能力管理；记录实际可选产品类型，重点确认 **Android 移动应用**与**云侧服务接入**所需条件。
4. 在最终提交前核实：个人或企业主体是否可申请、应用是否必须已上架、允许的数据级别、步数与睡眠读取项是否可选、测试阶段条件、所需材料。若页面仍不明确，使用官方在线工单说明“个人已实名、未上架 Android 预览 APK、HarmonyOS 中经卓易通运行、拟读取本人步数与睡眠”，询问 Android SDK 和云侧 API 的合适产品类型及资格。由用户确认后再提交工单。
5. 确认路线后再登记应用并申请最低必要的**读取**权限。首轮只考虑步数和已有睡眠记录，不申请写入、心率/血压或订阅能力。数据类型能否申请以后台实际开放范围为准。

Android 申请入口由官方 Codelab 链出：[申请 Health Service Kit](https://developer.huawei.com/consumer/cn/doc/hmscore-guides/apply-kitservice-0000001050071707)。本次网页工具无法稳定读取该页正文，因此不从旧文档推定 Android 当前资格。用户控制台的申请页是下一次核查的关键依据。

## 获准后实现与验收

1. 添加真实的“连接华为运动健康”入口；用户可跳过，聊天功能仍可用。申请权限时只列本版本实际使用且已获批的数据。
2. 实现账号授权、部分授权和撤销授权。云侧还要核查华为运动健康是否允许向 Health Service Kit 开放数据；官方健康隐私联接页面不能代替本应用 OAuth 授权。
3. 实现用户主动同步：读取有限日期范围，保留数据来源、记录时间和同步时间，区分未授权、无记录、同步失败和确认为零。
4. 由用户在真机完成授权并核对华为健康同一账号、同一天的记录。Android SDK 路线同时确认卓易通内 HMS 服务、授权跳转及返回流程，不能将普通 Android 示例通过视为卓易通验收。
5. 睡眠历史只用来补充近期作息，不宣称它能实时判断现在是否睡着。账号撤销授权、切换或记录过期后，停止使用相应状态推断。

云侧还有独立的华为健康数据开放授权。官方指南提供在健康 App 中开启或使用官方 HTML5 联接页的方法；指南明确其固定 client_id 仅控制隐私开关，**不能拿来作为本应用的 client_id**。[云侧：在华为健康中开放授权](https://developer.huawei.com/consumer/ru/doc/HMSCore-Guides/server-app-auth-example-0000001071757151)

## 当前不能承诺的事项

- 仅凭实名认证或开启 Android 活动权限即可读取华为健康。
- 个人未上架应用必然能拿到 Android / 云侧测试权限。
- 卓易通一定能使用宿主 HMS 或读取宿主健康数据。
- 云侧接口可以获得尚未同步的实时睡眠、全局屏幕使用情况，或规避开发者服务审批。

屏幕使用统计是另一套系统能力，不属于此次华为运动健康接入范围。
