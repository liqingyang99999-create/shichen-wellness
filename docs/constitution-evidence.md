# 体质问卷依据与实现说明

核对日期：2026-11-05。范围仅为本地 care preview；未改动已上线应用。

## 本版采用哪一版

现行推荐性国家标准为 **GB/T 46939—2025《中医体质分类与判定》**，2025-12-31发布、2026-04-01实施。本版采用其九类条目框架与第5章计分规则，不再把2009年的60题版称为现行完整版。[国家标准信息页](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=827D6D266BA52A2983F93638DA871028)、[市场监管总局发布说明](https://www.samr.gov.cn/xw/sj/art/2026/art_bbc0d96fbbb741a2a66d2f4f7a44fd82.html)

起草牵头单位北京中医药大学明确说明，新版工具由60条优化为27条。此信息用于确认版本，不把原量表的研究结果自动归于本软件。[北京中医药大学的正式发布介绍](https://www.bucm.edu.cn/bzyyw/44d4e7d1da5a44a4b1ea1d44505ddf63.htm)

## 实际核对的正式正文

从国家标准信息页正常进入“在线预览”，核对了正式封面、第5章及附录A表A.1—A.9；不是网上转载、征求意见稿或AI补写。正式预览第12页对应正文第6页（公式和阈值），预览第13—15页对应正文第7—9页（全部九表）。[官方在线预览入口](https://openstd.samr.gov.cn/bzgk/std/showGb?type=online&hcno=827D6D266BA52A2983F93638DA871028&request_locale=zh_CN)

问卷JSON采用简洁题意表述，逐项附源表号；未打包整份标准或官方页面图片。题意改写、合并重复提问及本软件呈现方式**尚未做等效性验证**，因此界面名为“现行标准框架版”，不称官方认证量表、临床验证产品或精确诊断。正式专业使用应核对标准原文及相应使用要求。

## 为什么保存27项、每人回答26题

附录九张表共30行，其中疲劳、心情低落、对寒冷的耐受各在平和表和另一表出现。去掉3次重复后是27个不同条目。湿热表又包含两个互斥的适用分支：白带相关题和阴囊相关题；每人只回答适用的一支。因此本软件保存27项、完整作答26项，九类型实际累计计分29次。这个计数是对正式表格结构的实现解释，不把26重新宣称为标准的条目总数。

UI先选择适用分支；`appliesTo`为`female`或`male`，共用`exclusiveGroup: damp_heat_sex`。选择反映该题是否适用，不从账号、姓名或聊天猜测。改选时应清除另一支旧答案。不愿回答或不适用时可停留为未完成；**不把空白、不适用当作1分**。计分函数要求恰好一个分支有值，否则不产出完整结果。

## 可复核的题目映射

| 类型 | 应用题号，按原表顺序 | 条目数 | 反向计分 |
|---|---|---:|---|
| 平和 | C01、C02、C03、C04 | 4 | C02、C03、C04 |
| 气虚 | C02、C05、C06 | 3 | 无 |
| 阳虚 | C07、C08、C04 | 3 | 无 |
| 阴虚 | C09、C10、C11 | 3 | 无 |
| 痰湿 | C12、C13、C14 | 3 | 无 |
| 湿热 | C15、C16、C17或C18 | 3 | 无 |
| 血瘀 | C19、C20、C21 | 3 | 无 |
| 气郁 | C03、C22、C23 | 3 | 无 |
| 特禀 | C24、C25、C26、C27 | 4 | 无 |

回顾时间为近一年；5个回答等级取整数1至5。反向条目只在平和类型中使用`6−原回答`，相同回答进入其他类型时仍为正向。原始分是本类型适用条目之和；转化分为：

`(原始分 − 适用条目数) / (适用条目数 × 4) × 100`

平和需自身至少60分，同时其他八类全部低于30分；若自身至少60分且其他八类全部低于40分，则为“基本是”。优先匹配前一条件。其余类型至少40分为“是”，30至不足40分为“倾向是”，低于30分为“否”。正式表以30—39分表述倾向区间，本实现对非整数转化分用`30 ≤ 分数 < 40`，不在判定前四舍五入。分数不是患病风险或概率。

多个类型可以同时达到阈值；全部保留，不强制选一个。`classifications`完整保存九类状态。`primary`优先返回达到40的类型，其次符合条件的平和，再其次只有倾向的类型；`tendencies`独立保留倾向，避免“基本平和”遮住其他提示。界面采用“相关表现”措辞保留不确定性。全部回答“有时”按规则会得到九类50分及八类偏颇阈值结果，不能擅自把中间选项解释为正常，也不应把这种回答模式当成八种疾病。

## 9题简测的边界

简测由项目从九类主题各选一个代表性表现设计，**不是经过验证的标准短版**。它只显示单项自述频率指数：1—5对应0、25、50、75、100。不套用标准量表的30/40/60阈值，不比较两个版本分数的高低。

项目规则将“经常/总是”（至少75）显示为该类相关表现较多；精力项至少75且其他项均至多25时，才提示平和相关表现。其他组合允许没有突出倾向；全部选“有时”不会被简测判成八类体质。多个突出表现可并存，不是统计置信度或医学筛查准确率。需要更完整信息时引导做标准框架版或与专业人员沟通。

## 接口与输入完整性

`scoreConstitution(mode, answers)`接收`simplified`或`standard`和题号到1—5整数的对象。返回`scores / primary / label / method / summary`，另附判定状态、实际作答数及标准版的原始分、分母和分支，供展示与复核。

漏题抛`ConstitutionInputError`，`code: INCOMPLETE`并带`missing`；双分支为`AMBIGUOUS_BRANCH`；非整数或越界为`INVALID_VALUES`；错问卷残留题为`UNKNOWN_ITEMS`。调用方应提示完成或修正，不能捕获后填默认1分继续算，也不能在版本切换时混用答案。

不在答题中主动诱发喷嚏、过敏或皮肤抓痕。这里回答长期体验，当前急性症状应进入应用的独立求助流程，不用体质结果解释或延误处理。
